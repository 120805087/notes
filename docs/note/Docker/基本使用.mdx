下文只列出Docker基本用法，更详细的操作命令，请参见[Docker](https://docs.docker.com/reference/)官网。

## 管理Docker守护进程

```base
sudo systemctl start docker     #运行Docker守护进程
sudo systemctl stop docker      #停止Docker守护进程
sudo systemctl restart docker   #重启Docker守护进程
sudo systemctl enable docker    #设置Docker开机自启动
sudo systemctl status docker    #查看Docker的运行状态
```

## 管理镜像
```base
docker images                   #列出本地镜像
docker pull <image>             #下载镜像
docker tag <image> <name>       #给镜像打标签
docker rmi <image>              #删除镜像
sudo docker rmi -f <image>      #强制删除镜像
docker history <image>          #查看镜像历史
```

## 管理容器
```base
docker ps                           #列出正在运行的容器
docker ps -a                        #列出所有容器
docker run <image>                  #创建并启动一个容器
docker run -d <image>               #创建并启动一个容器，并设置为后台运行
docker run -it <image>              #创建并启动一个容器，并进入容器
docker run -d -p 80:80 <image>      #创建并启动一个容器，并映射端口
docker exec -it <container> <cmd>   #进入容器
docker stop <container>             #停止容器
docker start <container>            #启动容器
docker rm <container>               #删除容器
docker rm -f <container>            #强制删除容器
docker logs <container>             #查看容器日志
docker inspect <container>          #查看容器信息
docker cp <container>:<path> <path> #从容器复制文件
docker commit <container> <image>   #将容器提交为镜像
docker save <image> > <file>        #将镜像保存为tar文件
docker load <file>                  #从tar文件加载镜像
```
